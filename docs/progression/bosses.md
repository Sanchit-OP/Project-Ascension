# Bosses

## Purpose

Defines boss progression, encounter roles, and unlock rewards.

## Boss Design Rules

- Every mandatory boss unlocks a new capability.
- Every boss tests preparation, not only damage output.
- Boss arenas must reinforce the planet identity.
- Boss loot must not obsolete the rest of the era.
- Bosses can be sourced from curated combat mods, but must be recontextualized around Project-Ascension progression.
- Existing boss kits should be modified or rebalanced rather than accepted as-is.

## Encounter Template

- Progression role
- Required prep
- Core mechanics
- Failure conditions
- Unlock reward
- Optional repeat reward

## Current Boss Sources

- **L_Ender's Cataclysm — confirmed, active.** The Moon's boss chain (M3.1) is Cataclysm's Ruined
  Citadel, relocated to a fixed spot on the Moon: the Ender Golem guards it, and on its death the
  Ender Guardian awakens and drops this project's own gateway key alongside its usual loot. See
  `plans/m3-vertical-slice.md` for the recipe
  (`ascension-compat-cataclysm`) — reused per-planet as more bosses get sourced.
- Bosses of Mass Destruction — still just a reference point, not yet used.
- More boss-source mods expected as later planets need bosses this one mod's roster doesn't fit.

## Design Warning

- Using boss mods is content sourcing, not combat design.
- If late difficulty is created mainly through stat resistance, players will experience longer fights rather than better fights.
- Boss pressure types still need to be specified explicitly for melee, ranged, mobility, and arena interaction.
- Existing mod bosses can serve as encounter foundations, but progression beats may also use non-boss objectives such as repairs, structure clears, and siege survival.
